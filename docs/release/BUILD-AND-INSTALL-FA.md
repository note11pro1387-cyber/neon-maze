# ساخت و نصب NEON MAZE روی Redmi Note 11 Pro

## گرفتن APK

1. فایل پروژه را در ریشهٔ یک GitHub repository قرار بده.
2. در GitHub وارد **Actions → Build APK → Run workflow** شو.
3. منتظر پایان اجرای Workflow بمان؛ فقط اجرای سبز با Artifact معتبر قابل‌قبول است.
4. از بخش Artifacts فایل `neon-maze-debug-apk-<run_number>` را دریافت و Extract کن.
5. APK را با فایل SHA-256 همراهش نگه دار؛ در صورت نیاز Hash را با `sha256sum -c app-debug.apk.sha256` در Linux/macOS بررسی کن.

## نصب روی گوشی

1. فایل APK را به حافظهٔ گوشی منتقل کن.
2. آن را از File Manager باز کن.
3. اگر MIUI/Android درخواست کرد، فقط برای همان برنامهٔ مدیریت فایل مجوز **Install unknown apps** را فعال کن.
4. APK را نصب و بازی را اجرا کن.
5. در اجرای اول Wi-Fi و Mobile Data را خاموش نگه دار تا مسیر آفلاین بررسی شود؛ چون آدرس Content Manifest در نسخهٔ فعلی خالی است، بازی باید از منابع داخل APK بالا بیاید.

## گزارش نقص

برای هر نقص، این موارد را ثبت کن: نام صفحه/مرحله، مراحل بازتولید، رفتار مورد انتظار، رفتار واقعی، اسکرین‌شات یا ویدئو، و آیا پس از Restart تکرار می‌شود. قبل از اصلاح، فایل Logcat همان اجرا را نیز ذخیره کن.

## نکتهٔ کلیدی دربارهٔ امضای Debug

GitHub Actions در هر Runner معمولاً Debug APK را با کلید Debug همان محیط امضا می‌کند. اگر نسخهٔ جدید با پیام امضای ناسازگار نصب نشد، نسخهٔ قبلی را حذف و APK جدید را نصب کن؛ این کار ممکن است داده‌های ذخیره‌شدهٔ محلی را پاک کند.
